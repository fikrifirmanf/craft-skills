The result avoids generic AI-UI defaults: no purple-to-blue gradient hero, no gradient text, no emoji as icons, no identical rounded card grid everywhere, no Inter-plus-indigo default without a reason. The palette and type have a deliberate character suited to a clinical-but-friendly scheduling tool, and the choice is stated in a short design note or comment.
